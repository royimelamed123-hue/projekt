# קניין הרגלים — תוסף לאוצריא

תוסף לאפליקציית **אוצריא** למעקב יומי/שבועי אחר הרגלים בלוח שנה עברי.

גרסה: **3.0.0** | דורש אוצריא **0.9.96+**

---

## 🆕 מה חדש בגרסה 3.0.0

### מערכת ציונים חדשה לחלוטין
שלוש שיטות חישוב שניתן לבחור לכל הרגל בנפרד:

- **הולך ומוסיף** — מתחילים את החודש ב-0 ועולים מעלה עם כל הצלחה. מדד להתמדה.
- **הולך ופוחת** — מתחילים את החודש עם 100 ויורדים עם כל פספוס. מדד לשמירה על רצף.
- **מצב סטטי** — מצב נתון של הצלחה מול פספוס. ממוצע מה שנעשה בפועל.

### סטטוס אונס
- ביום פעיל: ניתן להצהיר "אונס" — היום לא ייספר בחישוב (לא יועלה ולא יורד הציון)
- ביום לא פעיל: "אונס" מוגדר אוטומטית
- מחזור לחיצות בדף ההרגל: ריק ← הצלחה ← אונס ← פספוס (יום פעיל) / ריק ← הצלחה ← אונס (יום לא פעיל)

### שינויי שמות
- "בוצע" → **הצלחה**
- "לא בוצע" → **פספוס** (צובע אדום מיידית)

### ביטול הרגל חודשי
- הרגל חודשי הוסר — הרגל יומי מכסה את אותו הצורך בצורה מלאה
- הרגלים חודשיים קיימים הומרו ליומי אוטומטית

### שיפורי גרף יומי
- הגרף לא מציג ימים עתידיים
- ריחוף עכבר מעל נקודה מציג את הציון של אותו יום

### פיצ'רים נוספים
- **ממוצע הרגלים ספציפיים** — בחירת הרגלים וצפייה בממוצע החודשי שלהם לאורך הזמן
- **השוואה בהרגל יומי** — טאב ההשוואה עובד גם להרגלים יומיים (12 חודשים אחורה)
- **כפתורים בדף ההרגל** — ירדו שורה במסך צר במקום לדרוש גלילה אופקית

### מיגרציה אוטומטית
כל המשתמשים הקיימים עברו מיגרציה חלקה:
- שיטת חישוב ברירת מחדל: **מצב סטטי** (הכי קרוב לשיטה הישנה)
- הרגלים חודשיים הומרו ליומי
- כל הנתונים הקיימים נשמרו ללא שינוי

## פיצ'רים

### סוגי הרגלים
- **יומי (`x_times`)** — יעד מספרי לכל יום (למשל: 3 כוסות מים)
- **שבועי (`weekly`)** — יעד X פעמים בשבוע עם הגדרת ימים פעילים

לכל סוג ניתן להגדיר יעד שונה לכל יום בשבוע, וכן שיטת חישוב ציון.

### סטטוסים
- יומי: **V** (הצלחה), **X** (פספוס), **א** (אונס — לא נספר)
- שבועי: **W** (הצלחה), **N** (פספוס), **א** (אונס — לא נספר), **N_auto** (אונס אוטומטי לימים לא פעילים)

### שיטות חישוב ציון
- **הולך ומוסיף:** `(הצלחה / אפקטיבי) × 100`
- **הולך ופוחת:** `(1 - (פספוס / אפקטיבי)) × 100`
- **מצב סטטי:** `(הצלחה / (הצלחה + פספוס)) × 100`

כאשר **אפקטיבי** = ימי החודש פחות ימי אונס.

לשבועי — ציון חודשי = ממוצע ציוני השבועות לפי השיטה שנבחרה.

### ציוני קניין והגזמה
- **ציון קניין** — ציון מינימום להצלחה (ירוק)
- **ציון הגזמה** — ציון מינימום לכישלון (אדום), בין השניים = כתום

### סטטיסטיקות וגרפים
- ציון חודשי + ציון כולל (ממוצע כל הזמנים) לכל הרגל
- גרף התקדמות חודשי (להרגלים יומיים) — ללא ימים עתידיים, עם tooltip בריחוף
- השוואת תקופות — שבועות (לשבועי) או חודשים (ליומי)
- השוואת הרגלים — טבלה עם ציונים לכל ההרגלים לאותו חודש, בצבעי ספקטרום יחסי
- ממוצע הרגלים ספציפיים — ממוצע חודשי לקבוצת הרגלים שנבחרה

### ניהול הרגלים
- הוספה, עריכה, מחיקה, שכפול
- גרירה ושחרור לסידור מחדש (מבוסס Pointer Events)
- העברה לארכיון והסרה ממנו
- ביטול פעולה (Undo) לשינוי סטטוס, ארכיון, עריכה ושכפול

### סימניות וסינון
- 8 צבעי סימניה עם שמות מותאמים אישית
- סינון לפי סימניה, חיפוש טקסט, "לא סומן היום"
- שילוב כל הפילטרים יחד

### הערות יומיות
- הערה קצרה לכל הרגל בכל יום
- צפייה ועריכה מדף ההרגל

### תזכורות
- מספר תזכורות בשעות שונות
- בחירת ימים בשבוע לכל תזכורת
- טקסט מותאם אישית לכל תזכורת
- התראות דרך מערכת אוצריא

### גיבוי וייבוא
- ייצוא כל הנתונים לקובץ JSON
- ייבוא עם שתי אפשרויות: צרף לקיים / דרוס הכל
- גיבוי אוטומטי: יומי / שבועי / חודשי

### נעילת גישה
- סיסמה מוצפנת (SHA-256)
- מצב נעילה: בפתיחה בלבד / בכל יציאה מהתוסף
- הגדרה ראשונית / שינוי סיסמה / ביטול נעילה

### dark mode
- מסתנכרן אוטומטית עם ערכת הצבעים של אוצריא
- ניתן לשינוי ידני

### ניווט
- ניווט בין ימים (לסמן יום שעבר)
- ניווט בין חודשים בדף ההרגל
- לוח חודשי עברי מלא

## הוראות פיתוח

### עריכת קוד
JavaScript רגיל (ES6+) ללא build step. ניתן לערוך ישירות.

### מטמון סטטיסטיקות
מוגדר ב-`storage.js`:
- `statsCache` — תוצאות `calculateStatsForMonth` לפי הרגל+חודש
- `totalAvgCache` — ממוצע כולל לפי הרגל

**חשוב:** בכל שינוי נתונים יש לקרוא ל-`invalidateStatsCache(habitId)`.

### שמירה
`saveToStorageForHabit(habitId)` — לשינוי סטטוס (מפעיל `updateCardInPlace`)
`saveToStorage()` — לשינויים גדולים (מפעיל `renderHabits`)
שתיהן עם debounce של 500ms. בסגירת התוסף (`plugin.suspended`) — שמירה מיידית.

### Drag & Drop
מבוסס Pointer Events (לא HTML5 Drag API) — תואם WebView2 של אוצריא.
הלוגיקה ב-`attachDragHandle` ב-`interactions.js`.

### הוספת סוג הרגל חדש
1. הוסף ב-`configSelectedType` ב-`modals-config.js`
2. טפל ב-`setStatus` ב-`habits-logic.js`
3. הוסף רינדור ב-`render.js`
4. הוסף חישוב ב-`calculateStatsForMonth` ב-`interactions.js`
