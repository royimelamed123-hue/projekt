# קניין הרגלים — תוסף לאוצריא

תוסף לאפליקציית **אוצריא** למעקב יומי/שבועי/חודשי אחר הרגלים בלוח שנה עברי.

גרסה: **2.0.0** | דורש אוצריא **0.9.96+**

---

## תיאור

תוסף מלא למעקב הרגלים המשולב עם לוח השנה העברי. תומך בשלושה סוגי הרגלים, סטטיסטיקות מתקדמות, גרפים, השוואות, ועוד.

---

## פיצ'רים

### סוגי הרגלים
- **יומי (`x_times`)** — יעד מספרי לכל יום (למשל: 3 כוסות מים)
- **שבועי (`weekly`)** — יעד X פעמים בשבוע עם הגדרת ימים פעילים
- **חודשי (`monthly`)** — יעד X פעמים בחודש

לכל סוג ניתן להגדיר יעד שונה לכל יום בשבוע, וכן מספר ימי דילוג מותרים.

### סטטוסים
- יומי: **V** (בוצע), **X** (פספוס), **א** (אונס — לא נספר)
- שבועי/חודשי: **W** (בוצע), **N** (לא בוצע)

### ציוני קניין והגזמה
- **ציון קניין** — ציון מינימום להצלחה (ירוק)
- **ציון הגזמה** — ציון מינימום לכישלון (אדום), בין השניים = כתום

### סטטיסטיקות וגרפים
- ציון חודשי + ציון כולל (ממוצע כל הזמנים) לכל הרגל
- גרף התקדמות חודשי (להרגלים יומיים)
- השוואת תקופות — שבועות או חודשים (לכל סוגי ההרגלים)
- השוואת הרגלים — טבלה עם ציונים לכל ההרגלים לאותו חודש, בצבעי ספקטרום יחסי

### ניהול הרגלים
- הוספה, עריכה, מחיקה, שכפול
- גרירה ושחרור לסידור מחדש (מבוסס Pointer Events)
- העברה לארכיון והסרה ממנו
- ביטול פעולה (Undo) לשינוי סטטוס, ארכיון, עריכה ושכפול

### סימניות וסינון
- 8 צבעי סימניה עם שמות מותאמים אישית
- סינון לפי סימניה, חיפוש טקסט, "לא סומן היום"
- שילוב כל הפילטרים יחד

### הערות יומיות
- הערה קצרה לכל הרגל בכל יום
- צפייה ועריכה מדף ההרגל

### תזכורות
- מספר תזכורות בשעות שונות
- בחירת ימים בשבוע לכל תזכורת
- טקסט מותאם אישית לכל תזכורת
- התראות דרך מערכת אוצריא

### גיבוי וייבוא
- ייצוא כל הנתונים לקובץ JSON
- ייבוא עם שתי אפשרויות: צרף לקיים / דרוס הכל
- גיבוי אוטומטי: יומי / שבועי / חודשי

### נעילת גישה
- סיסמה מוצפנת (SHA-256)
- מצב נעילה: בפתיחה בלבד / בכל יציאה מהתוסף
- הגדרה ראשונית / שינוי סיסמה / ביטול נעילה

### dark mode
- מסתנכרן אוטומטית עם ערכת הצבעים של אוצריא
- ניתן לשינוי ידני

### ניווט
- ניווט בין ימים (לסמן יום שעבר)
- ניווט בין חודשים בדף ההרגל
- לוח חודשי עברי מלא

## הוראות פיתוח

### עריכת קוד
JavaScript רגיל (ES6+) ללא build step. ניתן לערוך ישירות.

### מטמון סטטיסטיקות
מוגדר ב-`storage.js`:
- `statsCache` — תוצאות `calculateStatsForMonth` לפי הרגל+חודש
- `totalAvgCache` — ממוצע כולל לפי הרגל

**חשוב:** בכל שינוי נתונים יש לקרוא ל-`invalidateStatsCache(habitId)`.

### שמירה
`saveToStorageForHabit(habitId)` — לשינוי סטטוס (מפעיל `updateCardInPlace`)
`saveToStorage()` — לשינויים גדולים (מפעיל `renderHabits`)
שתיהן עם debounce של 500ms. בסגירת התוסף (`plugin.suspended`) — שמירה מיידית.

### Drag & Drop
מבוסס Pointer Events (לא HTML5 Drag API) — תואם WebView2 של אוצריא.
הלוגיקה ב-`attachDragHandle` ב-`interactions.js`.

### הוספת סוג הרגל חדש
1. הוסף ב-`configSelectedType` ב-`modals-config.js`
2. טפל ב-`setStatus` ב-`habits-logic.js`
3. הוסף רינדור ב-`render.js` (`createDailyHabitCard` / `createWeeklyHabitCard` / `createMonthlyHabitCard`)
4. הוסף חישוב ב-`calculateStatsForMonth` ב-`interactions.js`
